# Script-to-Method Implementation Map

## Read This Reference When

Read this file before invoking, modifying, validating, or interpreting any bundled script. It records the primary scientific grounding, the production path now exposed, and the evidence needed before reporting a result.

## Compatibility and Supersession Notes

The original filenames remain stable. Legacy `--demo` options, where retained, are deterministic smoke fixtures; production use supplies explicit files, models, datasets, or manifests. No runtime result should be generated from a fixture and presented as study evidence.

The following original prototype patterns were replaced without rejecting their scientific source:

- synthetic lexical log-probabilities became the analytic Fast-DetectGPT criterion and model-backed inference;
- fixed detector F1 strings became measured calibration outputs;
- fixed headline weights became train/evaluate/predict separation over randomized experiments;
- a static Curie-style code scan became three explicit rigor layers;
- capitalized-term co-occurrence became a Text-to-Table/T³ preprocessing, adapter, and integration contract;
- keyword-only literature ranking gained BM25, dense, and listwise-reranker paths;
- source occurrence checks gained recursive schemas, source hashes, and raw/byte offsets.

## Interpretation Rule

Report both the **scientific source status** and the **executed implementation status**. For example:

> Source status: Fast-DetectGPT method inspected and implemented. Runtime status: analytic criterion smoke passed; model-backed Llama-3 inference NOT RUN because model dependencies/weights were unavailable.

This prevents two opposite errors: dismissing a supported method because its prototype was compact, and claiming empirical validation because a local executable passed a smoke test.
